# Sonvire Browser

**Sonvire** — быстрый, минималистичный и приватный настольный веб-браузер для Windows 10 / 11 (x64) на базе Electron 45 (Chromium), SolidJS и Tailwind CSS v4.

## Скачать Sonvire Browser (Windows 10 / 11 x64)

**[Перейти к последнему релизу (GitHub Releases) →](https://github.com/gulaevdan099-gif/sonvire-browser/releases/latest)**

Никакого Node.js или сторонних компонентов не требуется — просто скачайте один из двух архивов:

| Вариант | Что скачать на странице релиза | Как запустить |
|---|---|---|
| **Установщик (рекомендуется)** | `Sonvire-<версия>-win32-x64-Setup.zip` | 1. Распакуйте архив → 2. Запустите **`Install-Sonvire.cmd`** (без прав администратора) → 3. Ярлыки в «Пуске», на рабочем столе и «Приложения по умолчанию» настроятся сами |
| **Портативная версия** | `Sonvire-<версия>-win32-x64-portable.zip` | 1. Распакуйте папку `Sonvire-<версия>-win32-x64` → 2. Запустите **`Sonvire.exe`** (для режима флешки создайте пустой файл `portable.flag` рядом с `Sonvire.exe`) |

> **Если Windows SmartScreen покажет предупреждение:** для новых независимых сборок Windows может показать синее окно защиты — нажмите **«Подробнее» → «Выполнить в любом случае»**. Все архивы проверяются по `SHA256SUMS.txt`.

> **Автообновления:** после установки новые версии скачиваются автоматически быстрыми Ed25519-патчами (`~750 КБ`) в **Настройки → О браузере**. Файлы `latest.json` и `*-app-patch.zip` на GitHub скачивать вручную не нужно.

> **English summary:** Sonvire is a fast, privacy-focused desktop web browser for Windows x64 featuring crisp native DirectWrite typography, a deep Customization Studio (Dark / Obsidian Glass / Light themes, 7 accents + custom HEX picker, 5 one-click presets, Start Page wallpapers, left/right auto-hide sidebar, JSON theme backup), a real Performance & Optimization Engine (Balanced / Performance / Eco modes, one-click RAM optimizer, live Chromium process telemetry, Adblock LRU cache, SQLite WAL tuning), Private tabs, Split View, built-in page/video translation, Ed25519-signed auto-updates, and a clean standalone portable/per-user Windows distribution.

## Основные возможности

- **Плотная нативная типографика Windows DirectWrite**: чёткий, контрастный и читаемый шрифт по умолчанию (`bold`: body 600 / label 700 / heading 800, субпиксельное сглаживание DirectWrite на Windows 10 и Windows 11) с настройкой насыщенности (*Обычный* / *Средний* / *Плотный*), семейства шрифтов (*Системный* / *Гротеск* / *Гуманистический* / *Моноширинный*) и масштаба интерфейса (`90%` / `100%` / `110%`).
- **Студия глубокой кастомизации**:
  - **Темы и акценты**: *Графитовая тёмная*, *Обсидиановое стекло*, *Светлая* и *Системная* темы, 7 акцентных палитр + произвольный **HEX-цвет** с автоматическим контрастом текста по WCAG, а также **5 готовых пресетов в 1 клик** и **экспорт/импорт настроек оформления в JSON**.
  - **Компоновка и форма**: плотность интерфейса (*Компактная* / *Комфортная* / *Просторная*), скругление углов (*Строгое* / *Скруглённое* / *Капсулы*), интенсивность стекла (*Выкл* / *Лёгкое* / *Насыщенное*), снижение анимаций, расположение боковой панели **слева или справа**, **автоскрытие сайдбара**, а также настройка видимости кнопок верхней панели (включая кнопку «Домой» `Alt+Home`).
  - **Стартовая страница**: 6 встроенных градиентных обоев + загрузка **собственного фото** (`.png`/`.jpg`/`.webp`/`.avif`, хранится локально и защищено от сторонних сайтов) с ползунками размытия (`0–24 px`) и затемнения (`0–80%`), выбор числа колонок (`3–6`) и видимости виджетов.
- **Оптимизация браузера и контроль производительности**:
  - **3 режима работы**: *Сбалансированный*, *Максимум скорости* и *Эко-режим* (ускоренный сон вкладок через 2 мин, отключение тяжёлого размытия и автосброс ОЗУ по порогу).
  - **Оптимизатор памяти в 1 клик**: усыпляет фоновые вкладки, очищает V8 code cache, выполняет `PRAGMA wal_checkpoint(TRUNCATE)` и `PRAGMA shrink_memory`, показывая освобождённый объём ОЗУ в МБ.
  - **Живая телеметрия Chromium**: реальное потребление памяти по процессам (*Основной* / *Вкладки* / *GPU* / *Всего*), время холодного старта, размер HTTP-кэша с очисткой **без сброса cookies и авторизаций**, процент попаданий LRU-кэша Adblock (`4 096` записей), SQLite WAL + индексы, нулевой опрос телеметрии в фоне, `content-visibility` для списков и переключение **аппаратного ускорения GPU**.
- **Вертикальные вкладки, рабочие пространства и Split View**: плавное изменение ширины боковой панели (`220–380 px` через `requestAnimationFrame`), компактный режим (`64 px`), закреплённые сайты и разделение экрана (`Ctrl+\`) без перезагрузки вкладок.
- **Умный Omnibox (`Ctrl+K` / `Ctrl+L` / `Ctrl+T`)**: быстрый переход по сайтам, поиск по закладкам и истории SQLite, встроенный безопасный калькулятор и конвертер величин (`15% от 200`, `16 гб в мб`), быстрые команды браузера (`>`: оптимизация ОЗУ, Эко-режим, пресеты тем, перенос сайдбара, плотность шрифта).
- **Нативный блокировщик рекламы и трекеров**: фильтрация на сетевом и косметическом уровнях с микросекундным LRU-кэшем, счётчик заблокированных запросов на вкладку, гибкие белые и пользовательские списки.
- **Приватные вкладки (`Ctrl+Shift+N`)**: полностью изолированная сессия в оперативной памяти без записи истории, cookies и паролей на диск.
- **Автосон вкладок (Auto-Tab Hibernation)**: выгрузка неактивных вкладок со снимком состояния, восстановлением позиции прокрутки и черновиков форм.
- **Прокси и защищённые туннели**: поддержка HTTP, SOCKS5, VLESS Reality, Trojan, Shadowsocks, подписок и выборочной маршрутизации по доменам.
- **Встроенный перевод страниц и видео + локальный видеоплеер**: перевод веб-страниц на лету, озвучка/субтитры для видео (`Alt+T`) и встроенный плеер `sonvire://player`.
- **Менеджер паролей, закладки и загрузки**: шифрование секретов через Windows DPAPI (`safeStorage`), импорт/экспорт закладок (HTML), контроль загрузок с выбором папки и повтором.
- **Подписанные автообновления (Ed25519)**: быстрые патчи (`~0.5–1.5 МБ`) и полные сборки с проверкой цифровой подписи Ed25519 + SHA-256, атомарной заменой с автооткатом при ошибке, поддержкой **GitHub Releases 24/7** и **локального сервера с ПК**.

## Установка и запуск (Windows x64)

Готовые релизные архивы публикуются на **[GitHub Releases](https://github.com/gulaevdan099-gif/sonvire-browser/releases/latest)** (а при локальной сборке сохраняются в `release/dist/`) и **не требуют установленного Node.js**.

### Вариант 1: Установка для текущего пользователя (рекомендуется)
1. Скачайте `Sonvire-<версия>-win32-x64-Setup.zip` (или `Sonvire-<версия>-win32-x64-Setup.exe`) со страницы **[последнего релиза](https://github.com/gulaevdan099-gif/sonvire-browser/releases/latest)**.
2. Распакуйте архив и запустите **`Install-Sonvire.cmd`** (права администратора не требуются).
3. Браузер установится в `%LOCALAPPDATA%\Programs\Sonvire`, создаст ярлыки в меню «Пуск» и на рабочем столе и появится в **Параметры Windows → Установленные приложения** и **Приложения по умолчанию**.
4. Для удаления используйте стандартные параметры Windows или `Uninstall-Sonvire.cmd` в папке установки.

### Вариант 2: Портативная версия (Portable)
1. Распакуйте `Sonvire-<версия>-win32-x64-portable.zip` в любую удобную папку.
2. Запустите `Sonvire.exe`.
   - По умолчанию профиль хранится в `%APPDATA%\Sonvire`.
   - Для **полностью автономного портативного режима** (например, на флешке) создайте пустой файл **`portable.flag`** рядом с `Sonvire.exe` или запускайте `Sonvire.exe --portable` — все данные профиля будут сохраняться в `.\data` рядом с приложением.

### Проверка контрольных сумм (SHA-256)
Сверьте хэш скачанного архива с файлом `SHA256SUMS.txt` в PowerShell:
```powershell
Get-FileHash .\Sonvire-<версия>-win32-x64-portable.zip -Algorithm SHA256
```

## Приватность и безопасность

- **Никакой телеметрии и скрытых личных серверов**: Sonvire не отправляет аналитику и не подключается к сторонним прокси без явного действия пользователя.
- **DNS-over-HTTPS (DoH)**: настраиваемый выбор публичного резолвера (Cloudflare `1.1.1.1`, Google `8.8.8.8`, Quad9 или системный DNS).
- **Изоляция веб-контента**: все `<webview>` работают с включённой песочницей (`sandbox`), `contextIsolation: true` и отключённым `nodeIntegration`.
- **Локальное шифрование**: пароли, данные прокси и ключи синхронизации шифруются средствами ОС (`Electron safeStorage` / Windows DPAPI).
- **Криптографическая проверка обновлений**: каждый манифест `latest.json` подписывается ключом **Ed25519** (приватный ключ хранится строго вне репозитория в `%USERPROFILE%\.sonvire-release\update-signing-private.pem`), архивы проверяются по SHA-256, удалённые загрузки разрешены только по HTTPS.
- **Чистая релизная сборка**: при сборке с `SONVIRE_PROD_BUILD=1` тестовые хуки и отладочные IPC-каналы полностью исключаются из бандла.

## Windows SmartScreen и антивирусы (подпись кода)

Поскольку независимые сборки без платного EV/OV-сертификата не имеют накопленной репутации Microsoft SmartScreen, Windows может показать предупреждение *«Система Windows защитила ваш компьютер»* при первом запуске нового релиза (нажмите **Подробнее → Выполнить в любом случае**).

Чтобы максимально исключить ложные срабатывания Windows Defender и других антивирусов, в сборке Sonvire:
- С `Sonvire.exe` корректно удаляются устаревшие сертификаты базового Electron (исключён статус `HashMismatch`), а контрольная сумма заголовка PE (`OptionalHeader.CheckSum`) пересчитывается через Win32 `MapFileAndCheckSumW`.
- Портативный архив `Sonvire-<версия>-win32-x64-portable.zip` вообще не содержит `.cmd`/`.ps1` скриптов — только чистый `Sonvire.exe` и компоненты Chromium.
- Установщик не использует `-ExecutionPolicy Bypass`, `-WindowStyle Hidden` и скрытые дропперы; браузер не открывает локальные сетевые порты, пока прокси выключен.

### Автоматическая цифровая подпись Authenticode (`npm run release`)
Когда у вас появится сертификат подписи кода (например, бесплатный **[SignPath.io](https://signpath.io/)** для open-source проектов или **[Azure Trusted Signing](https://azure.microsoft.com/products/trusted-signing)**), `npm run release` подпишет `Sonvire.exe` и установщик автоматически через `signtool.exe`:
```powershell
$env:SONVIRE_SIGN_PFX = "C:\path\to\sonvire-codesign.pfx"
$env:SONVIRE_SIGN_PASSWORD = "your-cert-password"
npm run release
```

### Отправка релиза в Microsoft Defender (снятие ложных срабатываний)
1. Проверьте финальный `Sonvire.exe` или архив на [VirusTotal](https://www.virustotal.com/).
2. Отправьте файл в Microsoft Security Intelligence: **[microsoft.com/en-us/wdsi/filesubmission](https://www.microsoft.com/en-us/wdsi/filesubmission)** → *Software developer* → *Incorrectly detected as malware/malicious* (обычно обрабатывается за несколько часов).
3. Укажите SHA-256 из `release/dist/SHA256SUMS.txt` на странице релиза для прозрачной проверки пользователями.

## Автообновления и публикация релизов (в 1 команду)

Sonvire поддерживает два способа доставки обновлений пользователям: **GitHub Releases 24/7** (рекомендуется для публичной аудитории) и **прямой сервер с вашего ПК** (локально или через Cloudflare Tunnel).

### 1. Первичная настройка ключей подписи (1 раз)
```bash
# Генерирует приватный ключ Ed25519 в %USERPROFILE%\.sonvire-release\update-signing-private.pem
# и записывает публичный ключ + канал обновлений в update-channel.json
node scripts/update-keygen.mjs --github gulaevdan099-gif/sonvire-browser
```
> **Важно:** никогда не коммитьте `%USERPROFILE%\.sonvire-release\update-signing-private.pem` и `%USERPROFILE%\.sonvire-release\github-token.txt`, и сделайте резервную копию приватного ключа — без него ранее установленные браузеры не примут новые обновления.

### 2. Публикация обновлений через GitHub Releases (24/7)
Токен GitHub автоматически читается из `GITHUB_TOKEN` / `GH_TOKEN` или из защищённого файла `%USERPROFILE%\.sonvire-release\github-token.txt` (также поддерживается `gh auth login`). Выпустите обновление одной командой:
```bash
# Быстрый патч (~0.5–1.5 МБ): поднимает версию (2.6.0 -> 2.6.1), собирает prod-билд, подписывает Ed25519 и заливает на GitHub Releases
npm run publish-update -- --bump patch --notes "Исправления и ускорение работы"

# Полный релиз (быстрый патч + полные portable/Setup архивы)
npm run publish-update -- --bump minor --full --notes "Большое обновление Sonvire"

# Пробная сборка и подпись без публикации в сеть
npm run publish-update -- --dry-run
```

### 3. Раздача обновлений прямо с вашего ПК (или Cloudflare Tunnel)
```bash
# 1. Подготовить подписанные файлы в release/updates/
npm run publish-update -- --base-url https://<ваш-туннель>.trycloudflare.com --dry-run

# 2. Запустить локальный read-only сервер обновлений (127.0.0.1:4177)
npm run update:serve

# 3. (Опционально) Открыть публичный HTTPS-доступ с этого ПК через Cloudflare Tunnel
cloudflared tunnel --url http://127.0.0.1:4177
```
В самом браузере канал обновлений можно проверить или переопределить в **Настройки → О браузере → Обновления Sonvire**.

## Сборка из исходного кода

Требуется **Node.js 22+** и Windows 10/11 x64.

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Проверка типов и автотесты
npm run typecheck
npm run qa:unit
npm run qa

# Чистая релизная сборка (вырезает тестовые хуки и отладочные пути)
npm run build:prod

# Сборка автономного приложения в release/Sonvire-win32-x64/Sonvire.exe
npm run package

# Полная сборка дистрибутивов: portable ZIP + Windows Setup + SHA256SUMS.txt
npm run release

# (Опционально) Создать локальные ярлыки в меню «Пуск» и на рабочем столе
npm run shortcuts:local
```

При наличии [Inno Setup 6](https://jrsoftware.org/isinfo.php) (`ISCC.exe`) команда `npm run release` дополнительно соберёт однофайловый установщик `Sonvire-<версия>-win32-x64-Setup.exe` по шаблону [`scripts/sonvire.iss`](scripts/sonvire.iss).
